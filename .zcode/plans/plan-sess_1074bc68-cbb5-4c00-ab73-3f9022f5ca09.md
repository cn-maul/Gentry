## 前端整体重构方案

### 1. 监控总览（Dashboard）：右侧边栏承载「总览」
- **左侧边栏**：删除「新增监控」导航项（`AppLayout.tsx` + `layout.css` 的 `.nav-add` 样式）。「新增监控器」仍保留在总览页头部按钮，`/add` 路由不变。
- **Dashboard 布局**改为 `dashboard-body` 左右两栏：
  - 中间 `dashboard-main`：搜索框 + 分类筛选 + 分组监控卡片列表（现状保留，只去掉统计条）。
  - 右侧 `dashboard-side`（宽 ~260px，`position: sticky` 随滚动）：标题「总览」+ 4 张统计卡片（运行中监控/今日推送/待推送更新/推送账户，即现在的 stats-strip 内容竖排）。
- **响应式**（≤1100px）：右侧栏移到下方，统计卡变 2 列网格；移动端继续适配。

### 2. 规则库：可勾选 + 导出选中
- 表格新增**勾选列**：表头全选/半选（indeterminate），每行复选框。
- **后端** `exportScanRules` 支持 `ids` 查询参数（逗号分隔），仅导出选中规则；不传导出全部（向后兼容）。
- **前端** `exportScanRules(ids?)` 传参；导出按钮：有选中时导出选中（toast 显示条数），无选中导出全部；导出/导入后清空选择。

### 3. 推送通知：双栏布局
- 页面改 `push-body` 左右两栏：
  - **左栏「推送账户」**：账户卡片列表（名称 + 服务标签 + 测试/编辑/删除操作，去掉写死的"配置正常"状态行）；点卡片或编辑按钮 → 弹出编辑窗口（复用现有 Modal 表单）；「新增账户」弹新建窗口。
  - **右栏**：顶部「全局推送开关」切换，下方「推送模板」列表项（标题模板/内容模板两行，显示当前值或"默认…"），点击任一项 → 弹出「推送模板」Modal（两个字段 + 可用变量提示 + 保存）。内置默认模板保持不变（未填写时使用）。

### 4. 推送记录：固定高度 + 详情弹窗
- 每条时间轴卡片固定高度（~72px，超宽截断），只显示头部行（时间/状态徽章/站点/条数）+「查看详情」按钮。
- 点「查看详情」→ 弹窗展示完整信息：时间、状态、推送账户、条数、原因（跳过时）、错误详情、条目标题列表（数据已在前端，无需新接口）。

### 5. 设置：双栏分布
- `.settings-page` 改两列网格（`grid-template-columns: 1fr 1fr`），4 个区块（AI 模型/更新代理/版本与更新/关于）排成 2×2，PageHeader 跨整行；≤768px 退回单列。仅需 CSS 改动。

### 涉及文件
- 后端：`backend/web/scanrules.go`（导出支持 ids 过滤）
- 前端：`AppLayout.tsx`、`Dashboard.tsx`、`ScanRuleManagement.tsx`、`PushManagement.tsx`、`PushHistory.tsx`、`api/monitors.ts`、`layout.css`、`dashboard.css`、`settings.css`、`notifications.css`、`push-history.css`、`responsive.css`
